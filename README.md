## 📖 Overview

Welcome to the repository for my Photography Portfolio. This project is designed to be a fast, accessible, and visually striking platform for displaying professional photography. The user interface prioritizes the images, utilizing a clean, distraction-free layout with smooth transitions and optimized image loading.

Live Demo: [Portfolio](https://savitron-dev.github.io/Photography-Portfolio/)

## ✨ Features

* **Masonry Grid Gallery:** Dynamic layout that perfectly fits images of varying aspect ratios.
* **High-Resolution Optimization:** Lazy loading and modern image formats ensure crisp visuals without sacrificing performance.
* **Fully Responsive:** Seamless viewing experience across desktop, tablet, and mobile devices.
* **Light/Dark Mode:** Built-in theme toggler to suit viewer preferences.
* **Contact Integration:** Functional contact form for client inquiries and collaborations.

## 🚀 Getting Started

To run this project locally on your machine, follow these instructions.

### Prerequisites

* There is no need for Perquisites as Firebase is used for database which also handled backend.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/photography-portfolio.git
   ```

2. **Navigate to the project directory:**
   ```bash
   cd photography-portfolio
   ```

3. **To see Website**
   ```bash
   open index.html
   ```

4. **Start the development server:**
   ```bash
   nano index.html
   ```
